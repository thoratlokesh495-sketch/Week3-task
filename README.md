# Week 3 – Deep Learning, Text Classification and AI-Assisted Coding

In Week 3 of my internship, I worked with TensorFlow/Keras models, text classification, prompt engineering, and AI-assisted coding.

I built and compared two neural network models using the MNIST dataset. Model 1 achieved **97.36%** test accuracy, while Model 2 achieved **97.42%**.

I also developed an **IMDB movie review sentiment classification model** using TensorFlow and Keras. The model achieved **87.19%** test accuracy and classified reviews as positive or negative.

Along with machine learning, I experimented with different prompt styles and evaluated their outputs based on clarity, relevance, and usefulness. Finally, I used AI-assisted coding to create a small **Movie Review Sentiment Analyzer** using Gradio and documented the AI assistance and testing process.
